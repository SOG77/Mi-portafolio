// Sobre mí

Aprendo rápido y entrego completo

Soy desarrollador Full Stack y me interesa el punto donde una idea se convierte en algo que la gente puede usar sin pensarlo. No me quedo solo en la interfaz ni solo en el servidor: prefiero entender el problema entero y responder por el resultado.

Trabajo con Java y Spring Boot en el backend, React en el frontend, y PostgreSQL y Docker para que todo sea reproducible. Escribo código legible, documento lo que hago y entrego en iteraciones pequeñas para que siempre haya algo funcionando.

  • Código claroLegible antes que ingenioso. Que el siguiente lo entienda.
  • Entrega iterativaVersiones que funcionan desde el primer día.
  • Curiosidad constanteCada proyecto es una tecnología nueva bien aprendida.
